# Phase 3.1 — Mature HotFox Platform / Pre-release Engineering

Canonical product scope: `docs/HOTFOX_ROADMAP.md` heading «3.0 Mature HotFox Platform» (renumbered to 3.1 after the owner 2.9 VPN-recovery override).

## Objective

Evolve HotFox from a strong Android VPN application plus backend into a mature, operable VPN platform with a clear engine/UI boundary, signed control-plane metadata, capacity-aware AUTO, fleet/device operations, API versioning, offline policy and privacy-safe observability.

This is not a justification for a premature rewrite, a decorative R8 milestone, or a `VpnService` process split without evidence.

## Binding constraints

- TUN → HEV → SOCKS `127.0.0.1:10808` → Xray remains the truthful path;
- `CONNECTED` / `Защищено` only from `VpnSessionCoordinator` after path verification;
- Activity destruction must not imply VPN loss;
- AUTO remains a persisted mode; manual selection stays sticky;
- backend-authoritative entitlement; checkout `success=true` is not payment proof;
- remote metadata cannot disable TLS/REALITY, DNS leak protection, IPv6 fail-closed, path verification or checkout honesty;
- generated scoped device IDs only — no hardware fingerprinting;
- billing outage does not fabricate entitlement;
- control-plane outage does not wipe last-known-good servers.

## Repository implementation (IN PROGRESS)

- `HotfoxEngineFacade` — UI/notification/QS observe process-scoped engine state; facade is read-only.
- Signed control plane (`HotfoxControlPlane`) — inventory, region, weight, load bucket, maintenance/drain, role, policy version; ECDSA P-256; invalid/expired/unsigned keep last-known-good; TTL + 24h stale grace for AUTO.
- Capacity-aware AUTO — load/weight penalties plus local health; maintenance excluded from new AUTO picks; manual stays sticky.
- Device registry — UUID device ids, register/limit/revoke/rename, coarse last-active day bucket.
- `HotfoxApiCompatibility` — `CLIENT_TOO_OLD` / `SERVER_TOO_OLD` fail gracefully.
- `HotfoxOfflinePolicy` — entitlement continuity within expiry; no fabricated entitlement on billing outage.
- `HotfoxPrivacyTelemetry` — region/transport/billing/update/Shadow counters; rejects URLs/secrets.
- `HotfoxStateMigration` — preserves AUTO/manual, entitlement, routing, manual subscriptions.
- `HotfoxPlatformInventory` — privacy/security data inventory for architecture review.
- Remote-flag denylist extended: `vpn.fake_connected`, `vpn.skip_path_verify`, `vpn.disable_dns_protection`, `vpn.disable_ipv6_fail_closed`.
