# Phase 2.8 — Autopilot

## Objective

Make protection zero-touch for ordinary users without a second VPN session controller.

All automatic start/stop goes through `VpnRestartGate` / `CoreServiceManager`.

## Intent engine

`ConnectionIntentEngine` is pure: network + policy + entitlement + pause + session → `HotfoxConnectionIntent`.

Stale `eventGeneration` cannot override a newer decision.

## Required behaviors

- trusted home/office remain off when policy says so;
- unknown Wi-Fi and cellular connect by policy;
- pause 5/15/60 minutes or until network change;
- explicit user disconnect suppresses auto-reconnect until the network changes;
- captive portal waits with `Сеть требует авторизации` and can release VPN;
- boot/process start derives a fresh intent, never a stale session id;
- manual server selection is preserved.

Physical Android validation is not part of this engineering gate.
