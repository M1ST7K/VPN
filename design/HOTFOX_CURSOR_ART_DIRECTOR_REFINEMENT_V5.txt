3. P0 — FIX FOX ARTWORK MATTE
======================================================================

Current `hf_fox_bust` has an opaque rectangular dark canvas that is visibly different from app background on:
01/02/05/07/09.

This is unacceptable.

Create a clean transparent fox asset while preserving the same fox identity.

DO NOT repeat the old broken alpha extraction that made dark fur semi-transparent.

Required alpha algorithm / manual cleanup:
1. Load source fox art.
2. Sample background color distribution from outer border/corners.
3. Classify connected background from image edges using color distance, not brightness alone.
4. Preserve all non-background connected foreground.
5. Morphologically close/fill the foreground mask so dark interior fur is retained.
6. Alpha:
   - outside silhouette = 0;
   - interior = 255 or near 255;
   - only outer anti-aliased contour may use partial alpha;
   - feather width max ~1–2 px at target density, scaled proportionally.
7. No internal checkerboard visibility.
8. No rectangular matte.
9. No planet/arc.
10. No baked UI.

Produce previews:
verification/ui_rebuild/v5_assets/fox_checkerboard.png
verification/ui_rebuild/v5_assets/fox_hotfox_bg.png
verification/ui_rebuild/v5_assets/fox_alpha_diagnostic.png

Alpha diagnostic must report:
- percent alpha=0;
- percent alpha=255;
- percent 1..254;
- dark foreground pixels alpha<220.

Reject if dark fox body is materially translucent.

Resource:
prefer `hf_fox_bust_transparent` or an equivalent clear name.

Replace all production and debug visual references to opaque fox bust where the matte is visible.
