PURPOSE
-------
This document is a strict anti-drift visual contract for HotFox.
The 18 approved reference images are primary truth. This text is secondary.

NON-NEGOTIABLE RULE
-------------------
THE APPROVED REFERENCE FOR A SCREEN WINS OVER EVERY PROSE DESCRIPTION, OLD COMPONENT, THEME TOKEN, MATERIAL DEFAULT, AGENT PREFERENCE OR DESIGN OPINION.

You are not designing a new version.
You are not improving.
You are not reinterpreting.
You are not modernizing.
You are not adapting.
You are not taking inspiration.
You are recreating the UI inside each approved phone reference as literally as technically possible.

The correct result is not “same style”, “very close”, or “inspired by”.
The correct result is: no intentional visual deviation.

PIXEL-DIFF LOOP
---------------
For every screen:
1. preserve immutable reference;
2. extract/normalize inner-phone golden crop;
3. render implementation at canonical test viewport;
4. capture actual screenshot;
5. align/normalize;
6. create overlay/diff/heatmap;
7. calculate changed pixel count/percent, mean delta, max delta;
8. inspect bounding clusters;
9. fix;
10. repeat.

Do not mask visual errors.
Only dynamic VALUE regions may be stabilized/masked; their geometry and typography still must match.
