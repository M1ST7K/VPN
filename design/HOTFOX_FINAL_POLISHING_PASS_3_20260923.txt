2. P0 — FIX THE CONNECT CTA POWER ICON
======================================================================

CURRENT VISIBLE DEFECT:
On Home / Disconnected, the power icon inside the large orange "Подключить" CTA is visibly shifted toward the far left edge while the text remains visually centered.

This is unacceptable.

ROOT IMPLEMENTATION TO INSPECT:
- activity_main.xml
- connect_action
- HotfoxHomeV13.kt
- local TextView.startIcon helper

Current implementation uses a compound drawable on a wide AppCompatButton.

Do NOT keep a visual result where:
- power icon sits near the button's left edge;
- text is independently centered;
- icon and text do not read as one action label.

FINAL VISUAL TARGET:
The power icon + "Подключить" text must form ONE optically centered group.

Desired visual relationship:

[ power icon ]  [ Подключить ]

The COMBINED group is centered inside the CTA.

The icon should sit approximately 8–12dp before the text.

No icon floating at the far left.

No fake balancing with a second invisible icon.

No hardcoded raw screen-pixel X coordinate.

Implementation options:
A) create a dedicated centered CTA content layout/component;
B) calculate compound content width and center it robustly after measurement;
C) another responsive implementation that genuinely centers icon + text.

Do NOT solve with a one-device magic offset.

The same system must also behave correctly for:
- "Отключить"
- "Отменить"
- connecting labels if icon is present
- ERROR -> connect state

Check at:
- 360×800
- 393×873
- 412×915

Acceptance:
- icon/text group center differs from button center by <= ~2dp visually;
- spacing between icon/text is stable;
- no clipping;
- no state transition reintroduces drift.
