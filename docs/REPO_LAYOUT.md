# Repository layout

- `AGENTS.md` — mandatory instructions for Cursor/agents.
- `bootstrap/bootstrap_source.sh` — reconstructs the HotFox source/spec/reference.
- `bootstrap/payload/` — ordered verified payload chunks.
- `docs/` — Cursor setup and product engineering documentation.
- `V2rayNG/` — reconstructed Android project after bootstrap.

Large third-party binaries and private signing material are intentionally not versioned.
