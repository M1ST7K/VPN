# HotFox V13 — changelog трёх состояний Home

Реализация Views/ViewBinding поверх существующего `MainActivity`. Compose-пример из пакета не переносился. VPN/DNS/IPv6/entitlement/datapath не менялись.

Единая сцена: `hotfox_hero_scene.png` как top-aligned fill-width backdrop без Crop. Отдельная `HotFoxHeroArtwork` на Home скрыта — второй лисы нет. Колец, орбит и halo нет.

## Disconnected (бывший 05)

- Шапка HotFox + PRO по реальному entitlement.
- Чип «VPN выключен», заголовок «Не защищено», подпись «Подключитесь, чтобы защитить трафик».
- Подсказка «Одно касание до защиты».
- CTA «Подключить» — оранжевый градиент и иконка питания.
- Карточка «СЕРВЕР»: AUTO → «Автовыбор» / «Лучший сервер для вас» / бейдж AUTO и глобус.
- Shadow + Smart в одном ряду; Shadow — настоящий `SwitchCompat` на `HotfoxShadowStore`.
- Карточка «Подписка» с оранжевой обводкой.
- Нижняя навигация: активна «Главная».

## Connecting (бывший 06)

- Чип «Подключение», заголовок «Подключаем…», подпись «Создаём защищённое соединение».
- Горизонтальный indeterminate progress + строка стадии (без кругового прогресса вокруг лисы).
- CTA «Отменить» — тёмная заливка и оранжевая обводка.
- Сцена и слоты карточек те же, что у Disconnected.

## Connected (бывший 07)

- Чип «VPN активен» (зелёный) только при каноническом protected state.
- Заголовок «Вы защищены», подпись «В сети HH:MM:SS» с иконкой таймера.
- Две колонки трафика с реальными счётчиками (не 128/24 с макета).
- CTA «Отключить» — тёмная заливка.
- Навигация остаётся на «Главная», не на «Соединение».

## Прочее

- Debug painter (`src/debug`) красит те же production-view для скриншотов. Это не VPN E2E.
- Сравнение: `verification/ui/v13/` (actual / sbs / diff / overlay / REPORT.json).
- Pixel-perfect 1:1 не утверждается до свежих emulator-кадров и разбора diff.
