5. ASSET KIT INTEGRATION CONTRACT
======================================================================

Используй комплект как design-system source, но НЕ превращай Android app в bitmap UI.

Категории:

A. png/icons/
Можно использовать как декоративные визуальные слои внутри real native semantic controls.
Touch target задаётся родительским native control, минимум 48dp.

B. png/navigation/
Визуальные states nav.
Каждый destination остаётся отдельно clickable real navigation destination.

C. png/controls/
Это визуальные state assets.
Они НЕ должны создавать вторую независимую невидимую control layer поверх native semantics.

D. png/surfaces/
Card/input/sheet/segment/divider surfaces.
Text остаётся native.
Runtime values остаются native.

E. png/flags/
Можно использовать как static country visuals.
Никаких emoji-флагов, если kit даёт соответствующий asset.

F. png/illustrations/
Использовать строго по конкретному screen map.
Не распространять на другие экраны.

G. png/artwork/
Использовать строго по manifest/screens.json + конкретному reference.
Не добавлять artwork туда, где reference его не показывает.

H. png/fixture_apps/
ТОЛЬКО screenshot/test fixture.
Не подменять ими реальные installed-app icons в production.

I. references/
НИКОГДА не импортировать original boards в Android res как production assets.
Они только visual truth / comparison source.

J. sources/svg/
Это editable source geometry.
При необходимости лучше экспортировать Android-compatible resources из source,
чем повторно резать reference screenshots.

======================================================================
8. NATIVE UI / FUNCTIONAL SEMANTICS
======================================================================

Text:
- native TextView/EditText/etc;
- не raster;
- реальные localized strings;
- динамические values из реальной model.

PrimaryButton:
- один настоящий semantic action;
- visual background/arrow from asset system;
- existing listener сохраняется;
- accessibility сохраняется.

Rows:
- native row;
- leading visual;
- native title/subtitle;
- actual runtime trailing value;
- chevron OR switch;
- не создавать конкурирующие невидимые click overlays.

BottomNavigation:
- real navigation;
- отдельный clickable target;
- выбранный destination должен соответствовать actual destination;
- не глобализировать одну nav interpretation на все screens, если exact reference конфликтует.

BottomSheet:
- настоящий sheet;
- native scrim;
- native rows;
- Back / drag dismissal;
- accessibility focus handling.

Inputs:
- real editable field;
- selection/paste/IME;
- реальная validation;
- error semantics.

Switch/checkbox:
- state bound к существующей persisted model;
- никаких fake visual-only states.

Installed apps:
- production list = реальные installed apps;
- fixture app icons = только deterministic screenshot fixture.

9. TECHNICAL CORE NON-REGRESSION
======================================================================

Не ломай и не упрощай:

→ VpnService/TUN
→ HEV/tun2socks
→ local Xray SOCKS 127.0.0.1:10808

→ VPN server
→ Internet

Не считать подключением:
- наличие VPN icon;
- только TUN;
- только запущенный Xray;
- только открытый SOCKS;
- только animation completion.

Сохранять:
- DNS no-bypass;
- IPv6 route/fail-closed;
- loop prevention;
- clean disconnect/reconnect;
- stale async protection;
- truthful latency;
- real server state;
- real entitlement state;
- real traffic counters.
