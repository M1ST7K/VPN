GENERAL RECREATION FORMULA
--------------------------
For each output board:
1. Start from the exact matching reference image from the 18-image archive.
2. Match its board dimensions exactly.
3. Match the central phone mockup scale and vertical position.
4. Match the exact number of side callout panels.
5. Match the board title line exactly in the same location and approximate line length.
6. Match the small descriptor line under the title exactly in mood, tracking, casing, and spacing.
7. Match the upper-right metadata labels (ANDROID / API 24+ / DARK / PRIVATE / PREMIUM or equivalent where present).
8. Match the footer line with “HotFox” and “PRIVACY FREEDOM WITHOUT LIMITS” and the lower-right technical footer.
9. Recreate the inner UI screen shown on the phone 1:1 in composition and information hierarchy.
10. Match all callout connector lines, anchors, and directionality.
11. Preserve the premium visual tone with the same restrained orange, same near-black background, same soft glow behavior, same cream typography.

SECTION A — GLOBAL STYLE LOCK
=================================================

A1. BOARD CANVAS
----------------
Base background:
- extremely dark navy-black / warm black
- subtle blue-violet undertone
- very soft vertical and radial tonal variation
- no loud texture
- no obvious stock pattern
- feels deep, premium, technological, calm

Approximate background palette:
--bg-0: #05070D
--bg-1: #090B14
--bg-2: #0C0F18
--bg-violet-shadow: rgba(35, 24, 58, 0.18)
--bg-blue-shadow: rgba(21, 33, 60, 0.16)

Suggested CSS-like interpretation:
:root {
  --hf-bg-main: #070912;
  --hf-bg-deep: #05070D;
  --hf-bg-panel: rgba(16, 19, 30, 0.78);
  --hf-bg-panel-border: rgba(145, 150, 170, 0.18);
  --hf-text-main: #F6EDE8;
  --hf-text-secondary: rgba(246, 237, 232, 0.78);
  --hf-text-muted: rgba(246, 237, 232, 0.52);
  --hf-orange: #F78843;
  --hf-orange-bright: #FF8E4D;
  --hf-orange-dim: rgba(247, 136, 67, 0.30);
  --hf-green: #76EA77;
  --hf-line: rgba(255,255,255,0.12);
  --hf-callout-stroke: rgba(255,255,255,0.18);
}

Background behavior:
- soft edge glow behind phone
- no hard vignette
- no flat monochrome slab
- slightly illuminated vertical zone around the phone
- small highlights can appear near orange elements

A2. TYPOGRAPHY SYSTEM
---------------------
Language mix:
- Russian primary
- English appears selectively in UI labels and metadata
- preserve exact Russian copy as shown in references

Tone:
- premium, calm, informative, authoritative
- not corporate-bureaucratic
- not playful
- not aggressive

Suggested type family:
- Inter / SF Pro / similar neutral grotesk
- must feel modern, smooth, readable, not condensed
- do not use serif
- do not use futuristic novelty type

Weight behavior:
- board H1: bold / semibold
- board subtitle: regular, high tracking, uppercase/small caps style where appropriate
- phone UI H1: bold or semibold
- phone UI body: regular/medium
- callout titles: semibold/bold
- callout bullets: regular
- metadata: medium/light with expanded tracking

Tracking behavior:
- subtitles have noticeably increased letter spacing
- metadata in upper-right also spaced out
- footer slogan spaced out
- do not overdo tracking on body copy

Approximate size rhythm for 1448x1086 boards:
- board title: 60–72 px
- board subtitle: 15–22 px with generous tracking
- metadata labels: 13–18 px
- callout numbers: 24–34 px
- callout titles: 22–34 px
- callout bullets: 14–22 px
- phone wordmark “HotFox”: 16–26 px
- phone main screen title: 34–72 px depending on screen
- phone body copy: 13–22 px
- CTA text: 20–32 px
- bottom nav labels: 11–18 px

A3. COLOR LOCK
--------------
Primary text:
- cream / warm white
- never cold blue-white
- never grey-only
Approx:
#F5E9E1 to #FFF4ED depending on glow

Secondary text:
- muted cream/grey
Approx:
rgba(245, 233, 225, 0.72)

Muted meta:
- darker muted cream / grey-violet
Approx:
rgba(245, 233, 225, 0.45)

Brand orange:
- rich warm orange
- slightly copper / sunset tint
- not red-orange
- not yellow-orange
Approx:
#F78843 to #FF8E4D

Green:
- reserved exclusively for true protected/active success semantics
- bright but soft, not neon toxic green
Approx:
#76EA77 / #7AF27D

Borders:
- subtle grey-white opacity
- never heavy outlines
- panels must feel refined

A4. PHONE MOCKUP LOCK
---------------------
The phone is always a realistic premium Android device mockup:
- black/dark frame
- centered
- realistic bezel
- centered hole-punch front camera
- light reflection on metallic frame
- rounded corners
- soft shadow / glow into background

Do not:
- flatten the mockup
- remove bezel entirely
- switch to iPhone notch
- make the phone too small
- make the phone too wide
- distort perspective
- rotate device
- present as angled 3D product shot

A5. CALLOUT PANELS LOCK
-----------------------
The boards are not simple screenshots.
They are annotated presentation boards.

Each board includes:
- multiple left callout panels
- multiple right callout panels
- thin connector lines from panels to the phone
- numbered sections
- small icon or symbol beside some callout titles
- rounded dark translucent panel backgrounds
- fine soft border
- consistent internal padding

Panel style:
- rounded rectangle
- subtle border
- dark translucent fill
- enough blur/glow to feel premium but not glassmorphic

Bullet style:
- short explanatory bullets
- consistent indent
- no huge paragraphs
- highly readable

A6. METADATA LOCK
-----------------
Upper-right compact metadata generally reads in this family:
ANDROID • API 24+
DARK • PRIVATE • PREMIUM

This cluster must:
- stay top-right
- be small
- be spaced out
- feel technical and premium

Footer cluster:
Bottom-left:
HotFox
PRIVACY FREEDOM WITHOUT LIMITS

Bottom-right:
v2.0 • UI/UX SPEC • 2025
or the exact board footer as shown

Must remain in place and style.

A7. INNER UI LOCK
-----------------
The UI displayed inside each phone must feel like the same product family:
- same dark background
- same typography
- same orange CTA style
- same icon language
- same row/card language
- same bottom navigation language where applicable
- same overall padding logic

General inner UI tokens:
--screen-bg: #0A0C14
--screen-bg-deep: #070910
--card-bg: rgba(23, 23, 31, 0.92)
--card-border: rgba(255,255,255,0.08)
--row-divider: rgba(255,255,255,0.10)
--cta-fill: #F78A43
--cta-text-dark: #1A120D
--input-bg: rgba(19, 20, 30, 0.98)

Button style:
- broad rounded rectangle pill
- strong orange fill
- dark text
- arrow icon on right
- clean centered label

Secondary action style:
- textual, lighter
- not louder than primary CTA

A8. ICON LOCK
-------------
All icons must be coherent.
Use a single line-icon family or closely matched family.

Do not mix:
- outline and filled randomly
- thick and thin randomly
- geometric and doodle-like randomly
- Material icons and arbitrary glyphs incoherently

Icons must feel:
- crisp
- premium
- minimal
- Android-compatible
- not cartoonish
